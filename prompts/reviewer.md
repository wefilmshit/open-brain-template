# Reviewer Prompt

Review this Open Brain change for regressions and denominator drift.

Check:

- Does the UI copy match the actual search or recall behavior?
- Did the change alter production, or is it local/preview/shadow only?
- Are quality and speed measured separately?
- Are auth failures still closed?
- Are private paths, tokens, memories, or client data absent?
- Does the closeout name the exact commit, deploy ID, smoke results, caveats, and next action?

Lead with findings. If there are no findings, say that plainly and name residual risk.
